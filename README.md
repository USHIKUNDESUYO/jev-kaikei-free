仕訳は確認用の下書きです。モックの結果や確信度から、会計・税務処理の正確さや専門家の作業全体を代替する効果を保証することはできません。この配布には認証情報、顧客資料、モデルの重み、私用設定、元の非公開Git履歴を含めません。

TypeSafe AI の判断モデル **Jev** にレシートを見せて、勘定科目・消費税区分・私的支出かどうかを判定させ、仕訳を作るローカルツールです。
レシートがベルトコンベアで流れ、Jev の前で判定され、確信度がしきい値以上なら勘定科目のカゴへ、未満なら「裁きの間」（人の確認）へ落ちます。
「裁きの間」に落ちたものは 1 枚ずつ借方・貸方を直して確定し、仕訳CSVに出せます。

画面の言葉は魔界寄りにしてありますが、中身は普通の会計です。

| 画面の言葉 | 会計の言葉 |
|---|---|
| 選別の間 | 仕分け画面 |
| 裁きの間 | 人の確認（レビュー） |
| 金庫入り | 自動仕訳 |
| 帳面を持ち込む | 資料（CSV / JSON）を読み込む |
| 羊皮紙 | レシート |
| 帳簿の悪魔 | Jev |

仕訳CSV の「状態」列は会計の言葉（自動仕訳 / 要確認 / 確認済み / 修正して確定 / 保留）のままです。

Jev は文章を生成せず、渡した選択肢の中から確率と確信度つきで答えを返すモデルです（2026-09-15 公開、`jev-1.13.0`）。
APIの料金は提供元の契約と利用量によります。画面の費用表示は推計であり、請求額の上限を設定する機能はありません。

## 動かし方

依存ライブラリはありません（Python 3.10 以上の標準ライブラリだけ）。

```powershell
cd C:\dev\jev-kaikei
python -m jev_kaikei
```

ブラウザで http://127.0.0.1:8765/ が開きます。API キーがなければ自動でモック（キーワード判定）で動きます。

本物の Jev を使うには、`%USERPROFILE%\.secrets\jev-kaikei\.env` に次の 1 行を置きます。

```
TYPESAFE_API_KEY=jev_xxxxxxxx
```

ライブを使う場合は、[TypeSafe AIのコンソール](https://console.typesafe.ai/)で、ご自身のアクセス権、契約、料金、クレジット残高を確認し、APIキーを発行してください。以前のウェイトリスト、アクセス付与の所要時間、無料クレジットの案内は、現在の利用条件を保証しません。

ライブでは取引の文字情報を外部へ送ります。[送信項目](docs/DATA_FLOW.md)と[公式API条件の確認メモ](docs/API_TERMS.md)を読んでから切り替えてください。見本だけで操作を試す場合は、キーの有無にかかわらず`--mock`を指定します。

接続確認:

```powershell
python -m jev_kaikei --check
```

主なオプション: `--port 8765` `--mock`（キーがあってもモック） `--model jev-1.13.0`（版を固定） `--workers 8`（同時リクエスト数） `--no-browser`

## 使い方

1. **帳面を持ち込む**: CSV / JSON ファイル、見本の帳面、手で書く のどれか。
2. 読み込んだ順に Jev が判定し、ベルトに流れてカゴに落ちます。Space で一時停止、→ で 1 枚だけ進める。
3. **金庫入りのしきい値**（既定 0.80）を動かすと、その場で 金庫入り / 裁きの間 の振り分けが変わります。
4. **裁きの間**タブで、裁き待ちの分を 1 枚ずつ確認。Enter で確定、← → で移動、S で保留。「金庫入りも含めて全部見る」で自動分も見直せます。
5. **仕訳CSV** で出力（UTF-8 BOM 付き。Excel でそのまま開けます）。列: 日付, 借方勘定科目, 借方金額, 貸方勘定科目, 貸方金額, 税区分, 内消費税, 摘要, 確信度, 状態。

読み込んだデータと確定した仕訳はブラウザーのlocalStorageに残ります。「全部クリア」で取引・判定・仕訳・使用量を空にしても、事業内容などの設定は保持されます。

### 入力 CSV の列

列名は柔軟に拾います（UTF-8 / Shift_JIS どちらでも可）。

| 意味 | 認識する列名の例 |
|---|---|
| 日付 | 日付, 取引日, 利用日, date |
| 支払先 | 支払先, 店名, 取引先, 相手先, payee（なければ 摘要 を支払先として使う） |
| 摘要 | 摘要, 内容, メモ, 備考, memo, description |
| 金額 | 金額, amount。または 出金/出金額 と 入金/入金額 の 2 列 |
| 支払方法 | 支払方法, 決済方法（現金 / カード / 銀行 / 個人）。なければ設定の既定値 |
| 区分 | 区分, 収支（支出 / 収入）。なければ支出扱い |

`samples/receipts_sample.csv` と `samples/receipts_sample.json` が見本です。

## Jev への聞き方

1 レシート = 1 リクエストで、3 つの質問を同時に投げます（Jev は質問を並列に評価するので、質問を増やしても時間はほぼ増えません）。

| 質問 | 種類 | 内容 |
|---|---|---|
| `account` | Choice | 勘定科目マスタ（支出 37 択 / 収入 12 択、事業形態で増減）から 1 つ。各選択肢に `what / examples / not_for` を付けて混同を減らしています |
| `tax` | Choice | 課税 10% / 軽減 8% / 非課税 / 対象外 |
| `is_private` | Noul | 私的な支出・資金移動である確率 |

state には日付・支払先・摘要・金額・支払方法・収支を渡します。相手先と事業内容も、入力されている場合は含めます。Jev は関係ない情報が混ざると精度が落ちるためです。

判定後にコード側でルールを足しています。

- 消耗品費で 10 万円以上 → 固定資産（工具器具備品）や少額減価償却資産の特例を検討、と注意して人の確認へ
- 会議費・接待交際費で 1 人 1 万円以下 → 「1万円ルール」のヒント。会議費で 1 万円超は人の確認へ
- 私的支出の確率が 60% 以上なのに課税の科目（経費・売上） → 人の確認へ（カード引落しや預金利息でも 55% 前後が出るので、そこには適用しない）
- 口座間振替・内容不明（仮払金・仮受金） → 必ず人の確認へ
- 税区分は科目が課税のときだけ Jev の答えを採用（確信度 0.6 未満なら 10% を既定に）。租税公課や給料など固定の科目はマスタの値

貸方（収入なら借方）は支払方法で決めます: 現金 → 現金、銀行 → 普通預金、カード → 未払金、個人立替 → 事業主借（法人は役員借入金）。

## 勘定科目を変える

`jev_kaikei/accounts.json` を編集します。`code` は Jev に渡す ID（半角英数）、`what / examples / not_for` が Jev の判断材料です。
`entity` で個人事業主 / 法人専用、`mode` で売上の計上方法（入金時 / 請求時）を切り替えられます。

## 限界と注意

- OCR は入っていません。レシート画像から文字を起こす部分は別途必要です（Jev はテキスト専用モデル）。
- Jev は日本語では英語より精度が下がると公式が案内しています。しきい値は自分のデータで試しながら決めてください。
- 金庫入り（自動仕訳）もあくまで下書きです。確定前に必ず目を通してください。
- 仕訳CSV は汎用形式です。freee や マネーフォワード のインポート形式にはまだ合わせていません。

## CSV出力の文字列

数式の先頭と解釈され得る文字列には、CSV出力時に先頭へアポストロフィを付け、セル全体を引用符で囲みます。半角・全角の数式記号、先頭のタブや改行、記号の前の空白が確認対象です。金額などの数値、通常の文字列、元データとJSON出力は保持します。

表計算ソフトで編集・保存したCSVでは、この保護が失われる場合があります。再保存後の数式無効化や、すべての会計ソフトへの取込互換性を保証するものではありません。元の文字列を使う処理にはJSON出力を利用してください。[OWASPのCSV Injectionの説明](https://community.owasp.org/attacks/CSV_Injection)も参照できます。

CSV出力の回帰試験は、Node.jsがある環境で`node --test tests/test_csv_export.cjs`を実行します。アプリの利用自体にNode.jsは不要です。
