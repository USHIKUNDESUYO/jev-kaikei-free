# Jev会計の外部通信とAPI費用

まず画面と仕訳確認の流れを試す場合は、`--mock`を指定してください。モックは手元のキーワードによる判定で、TypeSafe AIへの判定依頼を行いません。ライブモードでは、読み込んだ取引の項目をTypeSafe AIへ送ります。

## 起動方法で通信の有無を選ぶ

| 起動する方法 | この版の動作 |
|---|---|
| `python -m jev_kaikei --mock` | APIキーが保存されていても、モックで起動 |
| `python -m jev_kaikei --mock --check` | 外部APIの接続確認を省略し、APIキーも読み取らず終了 |
| `python -m jev_kaikei --check` | キーがあればTypeSafe AIのモデル一覧へ接続して確認 |
| `python -m jev_kaikei` | キーが見つかればライブで起動。見つからなければモック |

ライブへの切り替えは、明示的な`--live`指定が必要な仕組みではありません。起動時のキーの有無で変わるため、モックで試す際は`--mock`を付けてください。画面には「コンセプトモック」または「ライブ」と表示します。既定のローカル接続先は`127.0.0.1:8765`です。

## ライブで送る取引の項目

ブラウザーは、取引一覧と設定を手元の`/api/classify`へ渡します。Python側で取引の項目と質問を組み立て、既定では`https://api.typesafe.ai/v1/systemone`へ送信します。取引1件につき、勘定科目・税区分・私的支出についての質問をまとめた1リクエストです。[公式API仕様](https://api.typesafe.ai/redoc)も参照してください。

| APIの取引項目 | 元の入力 |
|---|---|
| `date` | 日付 |
| `payee` | 支払先・取引先 |
| `description` | 摘要・メモ |
| `amount_jpy` | 金額 |
| `direction` | 収入・支出 |
| `payment_method` | 支払方法 |
| `counterparty` | 相手先。判定する取引に値がある場合 |
| `business_profile` | 設定した事業内容。入力されている場合 |

このほか、モデル名、質問、勘定科目の選択肢とその説明を送ります。固定版の入力画面はCSV・JSONの文字項目を読み込む実装であり、レシート画像やPDFの本体をJevへ直接送る処理ではありません。CSV・JSONから読み込んだ文字には取引先や個人の情報が含まれ得るため、ライブで使う資料の送信条件を確認してください。

APIキーはPython側で読み取り、TypeSafe AI向けの認証ヘッダーに使います。画面の設定応答にはキーを含めません。提供元の公開規約には、入力を学習に使わない条件や、保存・委託処理の説明があります。[公式API条件の確認メモ](API_TERMS.md)に確認日と条項を整理しました。利用者ごとの注文・別契約の内容や、実際の保存期間は未確認です。

## モックの表示とライブの請求額を区別する

2026年10月11日に確認した[TypeSafe AIの公式発表](https://typesafe.ai/blog/introducing-system-one-models-and-jev)は、入力100万トークン当たり0.042米ドル、出力は無料と記載しています。この版のコードも、その入力単価で費用を推計します。契約、料金改定、税、為替、実際の請求は別途確認してください。

画面の費用は、受け取った成功応答の入力トークンから計算した推計です。請求額の上限や課金停止の機能ではありません。クライアントには再試行があり、失敗や再試行時の請求がこの表示へすべて反映されるとは限りません。請求額は提供元の利用明細と照合してください。

モックの使用量と費用は、コードが計算した目安です。APIへの支払い実績、ライブの判定精度、専門家の作業を代替した実績として扱わないでください。既定のモデル名`jev-latest`も特定の不変なモデル版を固定する名前ではありません。

## 手元で保存する場所

ブラウザーは入力、判定結果、確定した仕訳、設定、使用量をlocalStorageへ保存します。画面を閉じても記録が残る仕組みです。「全部クリア」は取引・判定・仕訳・使用量を空にしますが、事業内容などの設定は残ります。別途保存したCSVや送信先の記録も、この操作では消しません。

APIキーは環境変数、利用者の秘密情報用フォルダー、作業場所の`.env`の順で探索します。キーや取引の保存ファイルをGitへ追加しないでください。

この案内は、基準ソース`cbce9930667a6bed2a628ae289e3e489b2347f28`の通信経路と、`--mock --check`のキー読み取りを止める修正に基づきます。ソフトウェアの無料利用と外部APIの料金、ソースの改変・再配布の許諾は、それぞれ確認が必要です。

## 画面のフォントとモックの通信範囲

画面の文字には端末にあるフォントを使います。Google Fontsなど外部のフォント配信先へのリクエストはありません。CSSのスプライトは同梱ファイルから読み込みます。

`--mock`を指定して起動すると、APIキーの読み取りと判定APIの呼び出しを行いません。ブラウザーからローカルのHTTPサーバーへ、入力と結果の取得のために通信します。ライブモードの送信項目と保存の扱いは、上の説明のとおりです。
